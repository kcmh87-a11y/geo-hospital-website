# 온율 ONYUL — Healthcare GEO Studio

병원 GEO/AIO 콘텐츠 전문가의 미래를 가정한 개인 브랜딩 연습용 웹사이트입니다. **“병원의 전문성을, AI가 이해하는 언어로.”**를 브랜드의 중심 문장으로 제안합니다. 온전한 정보와 균형 있는 표현을 지향하는 이름 ‘온율’을 바탕으로, 딥네이비·아이보리·차분한 골드의 전문 컨설팅 스튜디오를 디자인했습니다.

## 완성 화면과 다운로드

[미리보기 안내](preview/README.md)에서 PC·모바일 전체 캡처를 이미지로 확인할 수 있습니다. 이미지와 글꼴을 포함한 [단독 미리보기 HTML](preview/onyul-preview.html)도 보관했습니다. GitHub 파일 화면의 **Download raw file**로 저장한 뒤 컴퓨터의 브라우저에서 열어보세요. 소스 전체는 저장소의 **Code → Download ZIP**으로 내려받을 수 있습니다.

`preview/`는 제작 완료 시점의 미리보기 스냅샷입니다. 이후 수정 사항은 이 파일에 자동 반영되지 않으므로 최신 화면은 아래의 개발 서버 실행 방법으로 확인하세요. 이 저장소에는 웹사이트 자동 배포 설정이 없습니다.

## 실행

Node.js 22.12 이상이 필요하며, 클라우드에서는 Node.js 24.19.0으로 검증했습니다.

```bash
cd /workspace/geo-hospital-website
npm ci --cache /workspace/.cache/npm
npm run dev
```

개발 서버의 기본 포트는 **4321**입니다. 로컬 PC에서는 프로젝트 폴더에서 `npm ci`와 `npm run dev`를 실행하세요. 클라우드의 npm 캐시 경로는 쓰기 가능한 `/workspace`를 사용합니다.

```bash
npm run check          # Astro / TypeScript 검사
npm run build          # 정적 사이트 생성 → dist/
npm run preview        # 빌드 결과 확인
npm test               # 실제 Chromium 브라우저 기능·반응형·접근성 검사
```

테스트는 빌드 후 실행합니다. 클라우드에 설치된 `/usr/bin/chromium`을 자동 사용합니다. 다른 환경에서는 `npx playwright install chromium`으로 브라우저를 설치하거나 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`를 지정하세요. 테스트 전용 서버는 4322 포트를 사용합니다.

Astro 7은 에이전트 환경에서 서버를 백그라운드로 실행할 수 있습니다. `npm run dev -- status`, `npm run dev -- logs`, `npm run dev -- stop`으로 상태·로그·중지를 관리할 수 있습니다. 개발 도구 화면은 사이트에서 비활성화했습니다.

## 구성

- `/`: 전문가 소개, 6가지 서비스, SEO·GEO 비교, 가상 프로젝트 3건, 최신 칼럼, 대행사 협업 안내
- `/projects/dental-care/`, `/projects/orthopedic-care/`, `/projects/internal-medicine/`: 진료과별 가상 기획 상세
- `/insights/`: 분야별 칼럼 필터
- `/insights/[파일명]/`: Markdown으로 작성하는 칼럼 본문과 참고 자료
- `/contact/`: 문의 유형·서비스 선택, 필수 입력 검증, 내용 복사·파일 저장
- `/privacy/`: 실제 구현에 맞춘 개인정보 처리 안내
- `robots.txt`, `sitemap.xml`, `404.html`: 빌드 시 생성

## 내 정보 수정

**`src/config/site.ts`**에서 브랜드 소개와 `email`, `phone`을 수정하세요. 기본값은 비어 있으며 가상의 연락처를 표시하지 않습니다. 이메일을 지정하면 문의 정리 후 **이메일 앱 열기** 버튼이 나타납니다.

문의는 서버나 데이터베이스에 저장되지 않습니다. 연락처 미설정 상태에서는 복사·텍스트 파일 저장만 작동합니다. 이메일 설정 후에도 사용자가 자신의 메일 앱에서 직접 전송합니다. 자동 발송이나 수신 완료로 표시하지 않습니다. 향후 서버 전송을 추가할 때는 개인정보 안내를 실제 처리 방식에 맞게 수정해야 합니다.

프로젝트 내용은 **`src/data/projects.ts`**, 메인 문구와 서비스 설명은 **`src/pages/index.astro`**, 스타일은 **`src/styles/global.css`**에서 수정합니다.

## 칼럼 추가

`src/content/insights/`에 영문 파일명으로 `.md` 파일을 추가하면 목록과 상세 페이지, 사이트맵에 자동 반영됩니다. 최신 날짜 순으로 정렬되며 홈에는 최근 3편이 표시됩니다.

```markdown
---
title: '새로운 칼럼 제목'
description: '목록과 검색 결과에서 사용할 간결한 설명'
category: 'GEO · AIO'
date: 2026-10-17
readTime: 5
featured: false
---

도입 문단을 작성합니다.

## 소제목

본문을 작성합니다. 확인한 자료와 출처를 함께 제시하세요.
```

분야는 `GEO · AIO`, `콘텐츠 전략`, `병원 마케팅` 중 하나입니다. `src/content.config.ts`가 필수 항목과 분야를 검증합니다. 변경 후 개발 서버에서는 자동 반영되며, 공개 사이트에서는 다시 빌드·배포해야 합니다.

## 공개 도메인과 검색 설정

현재는 실제 도메인을 정하지 않았으므로 `noindex`와 `robots.txt`의 수집 차단이 기본입니다. 예시 도메인을 실제 사이트 주소처럼 노출하지 않습니다.

게시할 때 `.env.example`을 참고해 프로젝트의 `.env`에 **실제 HTTPS 도메인**을 지정하거나 호스팅 환경변수에 설정한 뒤 다시 빌드하세요.

```dotenv
SITE_URL=https://실제-사용할-도메인
```

도메인은 경로 없이 입력합니다. 위 값은 설명용이며 그대로 사용하지 마세요. 도메인 설정 후 다음 항목이 자동 생성됩니다.

- 페이지별 절대 canonical 주소와 Open Graph 주소·PNG 공유 이미지
- 모든 공개 콘텐츠를 포함한 절대 URL 사이트맵
- 검색엔진 수집을 허용하는 robots.txt (404 페이지는 계속 noindex)
- 서비스 정보와 칼럼의 JSON-LD 구조화 데이터

정적 결과물 `dist/`를 정적 호스팅에 배포하면 됩니다. 실제 도메인 연결과 배포는 아직 수행하지 않았습니다. 검색 노출이나 AI 인용은 보장하지 않습니다.

## 디자인·이미지·데이터

- Astro 정적 HTML, 로컬 Noto Sans KR / Cormorant Garamond 글꼴, 소규모 기본 JavaScript 사용
- 모바일 메뉴, 반응형 레이아웃, 키보드 포커스, 본문 바로가기, 모션 감소 설정 지원
- AI로 제작한 병원 콘셉트 이미지를 로컬 WebP로 최적화; 실제 고객 병원 사진이 아님
- 폰트 라이선스는 설치 패키지의 `OFL.txt`와 저장소의 `FONT_LICENSES.md` 참고
- 실제 경력·자격·후기·고객사·성과 수치 없음; 프로젝트와 칼럼은 연습용 샘플
- 실제 의료광고에 사용하는 콘텐츠는 의료진 검토 및 관련 법규·심의 대상 여부 확인 필요

## 검증 범위

타입 검사와 프로덕션 빌드, 전체 10개 콘텐츠 경로, 프로젝트·칼럼 이동, 필터, 모바일 메뉴, 문의 필수 입력·복사·다운로드, 360/390/768/1440px 가로 넘침을 점검합니다. 주요 5개 페이지에 WCAG 2.2 AA 관련 axe 자동 검사를 실행합니다. 자동 검사는 접근성 전체 준수를 인증하는 절차가 아니며 실제 사용성 검토를 보완하는 용도입니다.

설치 단계는 의존성과 생성물을 준비합니다. 새 클라우드 작업에서는 프로세스가 이어지지 않을 수 있으므로 개발 서버를 다시 시작해야 합니다. 환경 설정에는 재사용 설치 스크립트와 시작 지침을 별도로 저장합니다. 기존 체크아웃을 사용하고 별도 Git worktree를 만들 필요가 없습니다.
